Employee Profile App Using Flutter

Project Overview

This project is developed using Flutter and Dart as part of the Flutter UI Design Lab. It demonstrates UI design, responsive layouts, navigation, state management, form validation, animations, REST API integration, and testing.

Technologies Used

- Flutter
- Dart
- Visual Studio Code
- REST API
- Git and GitHub

How to Run the Project

1. Install Flutter and configure the development environment.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following commands:

flutter pub get
flutter run -d chrome
